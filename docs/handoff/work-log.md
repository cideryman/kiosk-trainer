- 기존 `이용신청` 상태와 자동 로테이션을 재사용하지 않고, 신규 `이용운영기록` 시트에 주차별 선택·완료 이력을 저장하도록 구현했습니다.
- 기본 운영 모드를 `MANUAL`로 두고, 일시 중단 주차에는 기존 자동 로테이션 트리거가 실행되어도 신청자 상태를 변경하지 않도록 보호했습니다.
- 관리자 신청 탭에 운영 주차 선택, 대상자 확정, 일괄 제공 완료, 운영 방식·중단 사유 설정을 추가했습니다.
- 기존 `이메일알림큐`를 `notificationType`·`referenceId` 기준으로 확장해 신규 신청 알림을 비동기로 등록하도록 했습니다. 이메일 알림 기본값은 꺼져 있으며 신청 저장은 이메일 큐 실패와 분리됩니다.
- 테스트 신청 표시·정리용 GAS API와 운영 개인정보 보호 조건을 추가했습니다.
- 정적 프론트 캐시를 `kiosk-cache-v329`, API 계약을 `2026-08-22.2`로 갱신했습니다.
- 운영 기록 중복 정리 API, 이름 중심 단일 목록, 역할이 분리된 작업 버튼, 테스트 신청 표시·필터·정리 UI를 추가했습니다.
- 중복 정리와 운영 화면 통합은 GAS 재배포 및 수동 검증 전이므로 P93 완료 상태로 변경하지 않았습니다.
- GAS 배포와 `setupGuestApplicationOperationsSheet()` 실행을 완료했습니다. 운영 기록 중복 정리, 운영 시트·이메일 큐·관리자 화면의 수동 검증이 남아 있어 완료 처리하지 않았습니다.
