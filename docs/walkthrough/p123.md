# 워크스루: 키오스크 주문 및 폴링 체감 속도 최적화 (P123)

P111(주문 제한/쿨다운), P112(준비완료 시각화), P116(메뉴 상세 TTS), P117(정원 관리 집계) 도입 이후 발생한 백엔드 중복 시트 읽기, 락 점유 구간 지연, 초기 중복 호출을 해소하여 키오스크 체감 속도를 대폭 개선했습니다.

---

## 주요 변경 사항

### 1. GAS 백엔드 중복 시트 I/O 제거 (`gas/40_Orders.gs`, `gas/60_Settings.gs`)
* **`getPublicOrderFeed()` 최적화**:
  * 기존에는 `getOrdersToday()`를 호출한 뒤 `getGuestSettings()`를 호출하여 내부에서 `getOrdersToday()`를 또 한 번 호출하는 **이중 시트 읽기**가 발생했습니다.
  * `getRawGuestSettings_()` 경량 함수를 신설하여 캐시에서 설정값만 빠르게 조회하도록 변경했습니다.
  * 주문 시트 읽기 횟수가 폴링당 **2회 → 1회(캐시 히트 시 추가 시트 I/O 0회)**로 감소하여 백엔드 부하를 50% 절감했습니다.
* **`buildGuestSettingsResponse()` 파라미터 주입 패턴 적용**:
  * `buildGuestSettingsResponse(settings, existingOrders)` 및 `getGuestSettings(existingOrders)` 형태로 확장.
  * 호출자가 이미 당일 주문 목록을 가지고 있는 경우 인자로 전달하여 내부 재조회를 완전히 건너뛰도록 개선했습니다.

---

### 2. 일반 키오스크 주문 락(Lock) 점유 구간 경량화 (`gas/40_Orders.gs`)
* **`placeOrder` 비게스트 경로 최적화**:
  * 키오스크 이용자(`isGuest === false`)의 주문 제한 정책(`kioskOrderPolicy`, `kioskCooldownMinutes`) 검증 시, 무거운 `getGuestSettings()`(운영일정, 정원집계 등 포함) 대신 `getRawGuestSettings_()`를 호출하도록 개선했습니다.
  * 락 점유 중 불필요한 주문 시트 재읽기를 원천 차단하여 주문 완료까지의 락 점유 시간을 **1~2초 단축**했습니다.

---

### 3. 프론트엔드 초기 중복 호출 차단 및 폴링 간격 완화 (`index.html`)
* **메인 화면 진입 시 0초 중복 호출 제거**:
  * 기존: `initCancellationAlerts()` 완료 즉시 `startCancellationPolling()`이 호출되어 `getPublicOrderFeed`를 0초 만에 2연속 호출.
  * 개선: `initCancellationAlerts()` 응답에서 `checkMyOrderStatus()`와 카드 상태 시각화를 일괄 완료한 뒤, `scheduleCancellationPolling()`으로 다음 요청을 지연 예약하여 불필요한 즉시 재호출을 제거했습니다.
* **폴링 주기 완화**:
  * `CANCELLATION_POLL_MS`를 10초에서 **15초**로 완화하여 분당 백엔드 요청 횟수를 6회에서 4회로 33% 절감했습니다.

---

### 4. 서비스 워커 캐시 상향 및 핸드오프 갱신
* **서비스 워커**: `service-worker.js` 캐시 버전을 `kiosk-cache-v369`로 상향.
* **핸드오프**: `handoff.md`에 P123을 최우선 '구현 완료·배포 대기'로 등록하고 다음 신규 작업 번호를 `P124`로 갱신.

## 사용자 배포 안내

이 작업은 **GAS 서버 코드 2개 파일**이 포함되어 있으므로 다음 절차가 필요합니다:
1. Google Apps Script 웹 편집기에서 `gas/40_Orders.gs`, `gas/60_Settings.gs` 내용을 덮어씌웁니다.
2. 새 버전으로 웹앱 배포를 진행합니다.
3. GitHub 저장소에 커밋/푸시하여 GitHub Pages 배포(`kiosk-cache-v369`)를 반영합니다.
