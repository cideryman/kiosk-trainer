## 주요 작업 내용

### 1. PC L자형 이중 네비게이션 (사이드바 + 상단 탭)
- **대분류 (좌측 세로 사이드바 / 열)**:
  - `⚙️ 관리자`, `🍳 주방`, `💬 후기` 메인 이동 및 `🛒 키오스크`, `🛵 배달왔삼`, `🖥️ 전광판`, `💖 온기보드` 외부 바로가기 링크를 폭 `220px` 다크 사이드바(`aside.admin-sidebar`)로 배치했습니다.
- **소분류 (본문 상단 가로 탭 / 행)**:
  - 주방 페이지: `[⚙️ 운영설정 | 📋 주문 | 📊 통계 | 📦 재고]`
  - 관리자 페이지: `[❤️ 이용자 | 🍪 간식 | 🔢 순서 | 📨 신청]`
  - 가로 탭과 세로 사이드바의 축을 90도로 완전히 분리하여 상단 헤더가 겹치지 않는 깔끔한 L자형 대시보드 레이아웃을 구축했습니다.

### 2. 모바일 슬라이딩 드로어 메뉴 & 가로 스크롤 탭
- **모바일 햄버거 버튼(`☰`)**:
  - `767px` 이하 환경에서 좌측 세로바가 화면을 차지하지 않도록 숨기고 헤더에 `☰` 버튼을 배치했습니다.
  - `☰` 버튼 클릭 시 좌측에서 사이드바 드로어가 스르륵 노출되며, 딤 오버레이를 누르면 닫힙니다.
- **가로 스크롤 탭 (Swipeable Tabs)**:
  - 세부 기능 탭 영역에 `overflow-x: auto; white-space: nowrap; -webkit-overflow-scrolling: touch;` 및 스크롤바 숨김(`::-webkit-scrollbar { display: none; }`)을 적용하여 터치 좌우 스와이프를 지원합니다.

### 3. 주방 상단 요약 카드 50:50 반반 균등 분할
- **`kitchen.html` 문구 축소**:
  - 기존 `오늘 전달받은 누적 온기 ❤️` ➡️ **`오늘 누적 온기 ❤️`**로 축소하여 모바일 좁은 화면에서의 가로 폭 팽창을 방지했습니다.
- **`css/style.css` 요약 카드 스타일 개선**:
  - `.summary-grid { display: grid; grid-template-columns: repeat(2, 1fr); gap: 10px; width: 100%; }`
  - `.summary-card { min-width: 0; overflow: hidden; }`
  - 텍스트 길이에 따라 한쪽 카드가 70%를 차지하던 현상을 해결하고 모바일 뷰포트에서도 **정확히 50:50 (1:1) 비율**로 맞춰지도록 완성했습니다.
