# 워크스루: 운영설정·관리자·후기 화면 본문 하단 '앱 업데이트 확인' 및 '관리자 나가기' 버튼 바 추가 (P128)

운영설정(`settings.html`), 관리자(`admin.html`), 후기(`reviews.html`) 화면에서 긴 설정 목록이나 테이블을 스크롤한 뒤, 화면 상단 햄버거 메뉴로 다시 거슬러 올라가지 않고도 본문 최하단에서 즉시 **최신 앱 업데이트 확인** 및 **관리자 세션 안전 종료(나가기)**를 할 수 있는 일체형 공통 유틸리티 푸터 바를 구축했습니다.

---

## 주요 변경 사항

### 1. 반응형 공통 유틸리티 푸터 바 마크업 추가 (`settings.html`, `admin.html`, `reviews.html`)
* **위치**: 본문 `<main>` 태그의 최하단에 배치하여 대시보드 및 테이블 스크롤이 끝나는 지점에서 자연스럽게 노출.
* **구성 요소**:
  * `[↻ 앱 업데이트 확인]` (`data-app-update-button`, `data-app-update-label`): 화면 코드 최신 캐시 업데이트 확인.
  * `[🚪 관리자 나가기]` (`data-admin-toolbar-lock`): 관리자 인증 해제 및 잠금 게이트로 즉시 복귀.
  * `상태 메시지 영역` (`data-app-update-status`): 업데이트 확인 중, 최신 버전 안내, 오류 등의 피드백을 안내하는 뱃지.

---

### 2. 세련된 대시보드 일체형 디자인 및 마이크로 인터랙션 적용 (`css/style.css`)
* `.admin-content-footer`: 본문 구획을 부드럽게 구분하는 점선 보더(`border-top: 1.5px dashed #E2E8F0`) 및 넉넉한 하단 여백(`padding: 24px 16px 40px`).
* `.btn-footer-update`: 깔끔한 화이트/슬레이트 톤, 호버 시 `↻` 아이콘 90도 회전 애니메이션(`transform: rotate(90deg)`), 클릭 시 자연스러운 눌림 피드백.
* `.btn-footer-logout`: 눈에 띄는 로즈/레드 톤(`color: #E11D48; background: #FFF1F2`), 호버 시 은은한 레드 글로우 그림자.
* `.admin-footer-status`: 에메랄드/민트 톤 둥근 필 뱃지 형태, 에러 시 로즈/레드 전환 및 부드러운 페이드인 애니메이션.
* **모바일 반응형 최적화**: 480px 이하 모바일 화면에서는 버튼이 풀위드 세로 1열 스택으로 전환되어 엄지손가락 터치가 편리하도록 최적화.

---

### 3. 기존 인증 및 업데이트 시스템과의 완전 연동 (`js/app.js`)
* **관리자 잠금 상태 연동**: `AdminAuth.init()` 및 `AdminAuth.render()`가 `[data-admin-toolbar-lock]` 속성을 자동 감지하여, 관리자가 로그인되어 있을 때만 하단 나가기 버튼이 표시되고, 클릭 시 토큰 삭제 및 즉시 잠금 화면으로 전환.
* **앱 업데이트 동기화**: `bindAppUpdateControls()`가 `[data-app-update-button]`을 감지하여 클릭 시 PWA 서비스 워커 업데이트를 검사하고, 사이드바와 본문 하단의 상태 메시지가 실시간으로 상호 동기화.

---

### 4. 서비스 워커 캐시 버전 상향 (`service-worker.js`)
* 정적 파일 변경 사항이 브라우저에 즉시 반영되도록 캐시 버전을 `kiosk-cache-v374` → `kiosk-cache-v375`로 상향.

## 사용자 수동 검증 안내

1. **GitHub 원격 저장소 푸시 및 Pages 반영**:
   - `kiosk-cache-v375`가 적용되도록 브라우저 새로고침을 실행합니다.
2. **화면별 동작 확인**:
   - **운영설정(`settings.html`)**:
     - 관리자 로그인 후 맨 아래로 스크롤하여 카드 5 하단에 `[↻ 앱 업데이트 확인]` 및 `[🚪 관리자 나가기]` 버튼 바가 정상 노출되는지 확인.
     - `[↻ 앱 업데이트 확인]` 클릭 시 "최신 버전을 확인하고 있습니다" → "현재 최신 버전입니다" 상태 뱃지가 부드럽게 표시되는지 확인.
     - `[🚪 관리자 나가기]` 클릭 시 세션이 종료되고 관리자 잠금(로그인) 화면으로 즉시 전환되는지 확인.
   - **관리자(`admin.html`)**:
     - 이용자 목록 또는 간식 목록 하단에서 유틸리티 바가 동일하게 동작하는지 확인.
   - **후기(`reviews.html`)**:
     - 후기 카드 목록 하단에서 유틸리티 바가 동일하게 동작하는지 확인.
